Test example: Students complete the same Chapter Safety Test in Google Classroom after instruction. The teacher scores all responses with the same answer key. Required accommodations are provided. Retakes assess the same learning targets using the same scoring scale, and earlier and later scores are retained to measure growth.
Shop-project example: Students complete the same project guide and submit the rubric document in Google Classroom. Students complete the reflection sections; the teacher scores safety, measurement and precision, craftsmanship, and completion using the same four-level rubric. Physical performance is observed and scored by the teacher. Resubmitted projects use the same rubric, and both results are retained.
